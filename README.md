# ✉️ Веб-сервис управления рассылками

Курсовая работа по разработке веб-приложения на базе фреймворка **Django**. Проект представляет собой автоматизированный сервис для создания, настройки и ручного запуска email-рассылок клиентам с возможностью пакетного логирования и разграничения прав доступа.

---

## 📋 Реализованный функционал (Критерии оценки)

В ходе выполнения работы были полностью реализованы следующие требования:
* **Архитектура БД:** Созданы модели данных для получателей (`Recipient`), сообщений (`Message`), рассылок (`Mailing`) и результатов (`MailingAttempt`) строго по ТЗ.
* **Бизнес-логика отправки:** Реализован обработчик ручного запуска рассылки с циклом отправки писем каждому клиенту.
* **Валидация:** Добавлена динамическая валидация временных интервалов рассылки (блокировка отправки, если текущее время не входит в разрешённый диапазон).
* **Batch-логирование:** Логи попыток отправки сохраняются в базу данных пакетно с использованием механизма `bulk_create` (batch).
* **Авторизация и роли:** Разработан личный кабинет пользователей с кастомной авторизацией по Email (без username) и верификацией учётной записи через токен, отправляемый на почту.
* **Безопасность:** Реализовано разграничение прав доступа. Пользователи видят и редактируют только свои данные (строго по `owner`). Выход из системы защищён через POST-запрос по стандарту Django 5.
* **Кэширование:** На главной странице развёрнут Dashboard со счётчиками статистики, данные для которого берутся из кэша (`LocMemCache` в шаблонах на 60 секунд).

## 🚀 Инструкция по локальному запуску

### 1. Клонирование репозитория и переход в папку
```bash
git clone <ссылка_на_твой_репозиторий>
cd mailing_service
```

### 2. Настройка виртуального окружения
```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка всех необходимых зависимостей
```bash
pip install -r requirements.txt
```

### 4. Конфигурация переменных окружения
В корне проекта уже подготовлен файл-шаблон `.env.example`. Создайте на его основе локальный файл `.env` командой:

# Для Windows (в PowerShell):
Copy-Item .env.example .env

### 5. Применение миграций базы данных
```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Создание учётной записи администратора (Суперпользователя)
```bash
python manage.py createsuperuser
```

### 7. Запуск локального сервера разработки
```bash
python manage.py runserver
```
После запуска проект будет доступен в браузере по адресу: `http://127.0.0`.  
*Примечание: отправка писем настроена в режиме `console.EmailBackend`. Текст писем и ссылки верификации при регистрации будут отображаться прямо в терминале.*
